#Weather Impact on Sales Analytics (Thailand)

##Overview

This project builds an end-to-end data pipeline on GCP to analyze how weather conditions impact sales performance across Thailand.

## Business Problem

Do temperature and rainfall affect product sales?

##Key Idea

* Hot weather → beverage sales increase
* Rainfall → customer traffic decreases

## Architecture (Planned)

Weather API + Sales Data → GCS → BigQuery → dbt → Dashboard

##Tech Stack

* Google Cloud Platform (GCS, BigQuery)
* Python
* dbt
* Airflow
* Power BI
